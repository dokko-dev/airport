# CHECKPOINT — 공항 보안 검색

React + TypeScript + React Three Fiber로 만든 단일 브라우저 역할 전환형 3D 게임 프로토타입입니다. 준비 → 비공개 인계 → 수색 → 압수/시간 종료로 하나의 게임이 완료됩니다.

## 실행

Node.js 22.12 이상(현재 검증: 24.19.0), npm이 필요합니다.

```sh
npm install
npm run dev
```

재현 가능한 설치에는 `npm ci`를 사용합니다. `npm run build`는 타입 검사 및 배포용 빌드, `npm test`는 게임 규칙 테스트를 실행합니다. 외부 API 키, 서버, 데이터베이스, 외부 모델·폰트 다운로드가 필요하지 않습니다.

## 조작

1. **훈련 시작하기**를 누릅니다. 준비 시간은 120초입니다.
2. 큰 덮개 앞쪽의 **메인 지퍼 손잡이**를 클릭하고 큰 덮개를 클릭해 들어 올립니다. 드래그로 회전, 휠로 확대합니다.
3. 옷가지를 클릭해 옮긴 뒤 안쪽 작은 주머니의 지퍼를 클릭합니다. 추가한 천 덮개는 노출된 지퍼를 하나씩 클릭해 엽니다. 전면 포켓은 별도의 지퍼로 엽니다.
4. 필요하면 지퍼를 추가합니다. 1·2·3포인트 순서로 소모하며 최대 3겹, 총 8포인트입니다. 실행 취소로 복구할 수 있습니다. 추가 공간은 고정된 안쪽 포켓 범위 안에서 천 두께를 갖고 쌓입니다.
5. 색상과 회전을 선택하고 열린 수납공간에 장치를 배치합니다. 작은 포켓은 90도 회전한 장치가 입구를 통과하지 못합니다. 배치는 공간별 고정 슬롯을 사용하며 옷과 장치는 별도 높이를 차지합니다.
6. **가방 제출하기**를 누르고 수색 담당자에게 기기를 넘깁니다. 모든 덮개가 닫히며 준비 정보가 UI에서 사라집니다. 준비 시간 종료 시 배치하지 않은 장치는 메인 공간에 자동 배치됩니다.
7. **수색 시작** 후 90초 안에 직접 열고 조사합니다. 옷을 선택한 후 **옷가지 들어 올리기**로 아래를 확인합니다. 손전등은 마우스 방향으로 빛과 그림자를 바꿉니다.
8. 가상 장치를 클릭한 후 **선택 물품 압수**를 누르면 수색팀 승리와 경보가 발생합니다. 시간 종료 시 밀반입팀이 승리합니다.

## 구조

- `src/game.ts`: Zustand 상태, 단계 전이, 포인트·깊이 제한, 실제 크기/입구 검사. 향후 서버가 이 규칙을 권위 있게 실행할 수 있도록 렌더링과 분리했습니다.
- `src/Bag.tsx`: 절차적 곡면 외피, 두께가 있는 덮개와 천, 안쪽 포켓, 지퍼 레일·이빨·손잡이, 봉제선, 라벨, 물품, 조명 및 카메라.
- `src/App.tsx`: 한국어 준비·인계·수색·결과 화면과 Web Audio 경보.
- `src/style.css`: 반응형 공항 검색대 UI와 Tailwind CSS 연결.
- `src/game.test.ts`: 제약 조건과 단계 전이 회귀 테스트.

모델의 1 단위는 20cm에 해당합니다. 장치는 12.8 × 2.8 × 7.6cm이며, 외형 페인팅은 충돌 크기에 영향을 주지 않습니다. 수색 시 닫힌 공간의 장치는 표시하거나 강조하지 않습니다. 옷가지가 메인 장치를 실제 깊이로 가립니다.

## 현재 범위와 제한

배낭 1종, 단일 장치, 고정 슬롯 배치, 전체 색상 페인팅을 제공합니다. 외피는 곡면 메시이며 안감·지퍼·봉제선은 별도 기하 구조로 제작했습니다. 천은 강체 애니메이션이며 천 물리 시뮬레이션은 없습니다. 자유 드래그 배치와 일반 충돌 해결, 부분 브러시 페인팅, 자유 수납구역 편집, 가위, 캐리어·크로스백, 컨베이어 이동, 온라인 로비와 Socket.IO 멀티플레이어는 아직 구현하지 않았습니다. 한 브라우저 역할 전환은 신뢰 기반이며, 개발자 도구에 대한 정보 보안은 제공하지 않습니다.
